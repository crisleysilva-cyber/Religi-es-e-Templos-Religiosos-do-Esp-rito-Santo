# Religi-es-e-Templos-Religiosos-do-Esp-rito-Santo
catalogar, documentar e valorizar a diversidade religiosa presente no estado do Espírito Santo, reunindo informações sobre igrejas, templos, santuários, terreiros, centros espirituais e outros espaços religiosos.  O objetivo é promover conhecimento, respeito à diversidade religiosa, turismo cultural e preservação histórica..
